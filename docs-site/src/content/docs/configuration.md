## Добавление Yandex Station в Music Assistant

1. Откройте **Music Assistant → Настройки → Плееры**.
2. Нажмите **«+ Добавить»** и выберите **Yandex Station**.
3. Следуйте инструкциям на экране для настройки провайдера.

## Параметры подключения

| Параметр | Значение |
|:---------|:---------|
| **Сервис** | [https://yandex.ru/alice/station](https://yandex.ru/alice/station) |
| **Метод аутентификации** | Yandex X-Token |
| **Макс. качество звука** | FLAC (lossless) |

Подробное описание всех параметров смотрите в диалоге настройки провайдера в Music Assistant.
