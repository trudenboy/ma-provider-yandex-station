## Добавление Yandex Station в Music Assistant

1. Откройте **Music Assistant → Настройки → Плееры**.
2. Нажмите **«+ Добавить»** и выберите **Yandex Station**.
3. Выполните вход одним из способов ниже.

## Способы входа

Провайдер поддерживает три способа аутентификации:

### 1. Device Flow *(рекомендуется)*

Откройте URL верификации на любом устройстве и введите короткий код.

1. Нажмите **«Login with device code»**.
2. Откроется страница с коротким кодом и ссылкой на Яндекс.
3. Перейдите по ссылке на телефоне или другом устройстве, войдите в аккаунт Яндекса и введите код.
4. После подтверждения окно закроется автоматически.

Device Flow сохраняет `x_token` и `refresh_token`, что позволяет тихо обновлять учётные данные при истечении музыкального токена или самого `x_token` — переавторизация не потребуется.

### 2. QR-код

Сканируйте QR-код приложением Яндекс на телефоне.

1. Нажмите **«Login with QR code»**.
2. Отсканируйте QR-код в официальном приложении Яндекс.
3. Подтвердите вход в приложении.

QR-метод сохраняет только `x_token` + музыкальный токен (без `refresh_token`). Обновление музыкального токена из `x_token` работает; при истечении `x_token` потребуется повторный вход.

### 3. Cookies *(запасной вариант, расширенные настройки)*

Вставьте cookies из браузера passport.yandex.ru. Используйте, только если Device Flow и QR недоступны.

1. В браузере откройте `passport.yandex.ru/profile` и войдите в аккаунт.
2. Экспортируйте cookies расширением «Copy Cookies» (JSON-массив) или любым другим способом.
3. В настройках провайдера (Расширенные) вставьте строку в поле **«Browser Cookies»** и нажмите **«Login with Cookies»**.

Cookies-вход сохраняет `x_token` + музыкальный токен (без `refresh_token`).

## Remember session

Переключатель **«Remember session (auto-refresh token)»** (по умолчанию включен).

- **Включён** — сохраняется `x_token` (и `refresh_token`, если доступен), MA тихо обновляет музыкальный токен при истечении без вмешательства пользователя.
- **Выключен** — хранится только музыкальный токен. По истечении нужно заново пройти процедуру входа — тихого обновления не будет. Полезно, если вы не хотите оставлять долгоживущие учётные данные в конфиге.

## Каскад обновления токенов

При каждой инициализации провайдера и при получении 401/403 от Quasar API выполняется каскад:

1. **Fast path** — используется сохранённый музыкальный токен как есть.
2. **x_token → music_token** — если музыкальный токен истёк, запрашивается новый у Yandex Passport по `x_token`.
3. **refresh_token → полный триплет** — если `x_token` тоже истёк, но есть `refresh_token` (Device Flow), атомарно обновляются все три токена.
4. **Terminal** — если ничего не сработало, все три токена очищаются и требуется повторный вход.

## Сброс авторизации

Кнопка **«Reset authentication»** очищает все три токена (`x_token`, `music_token`, `refresh_token`). После сброса потребуется заново выполнить вход.

## Параметры

| Параметр | По умолчанию | Описание |
|:---------|:-------------|:---------|
| **Login with device code** | — | Device Flow (рекомендуется). |
| **Login with QR code** | — | QR-код через приложение Яндекс. |
| **Remember session** | Включён | Хранить ли долгоживущие токены для тихого обновления. |
| **Browser Cookies** *(расш.)* | — | JSON-массив cookies с passport.yandex.ru (запасной способ). |
| **Login with Cookies** *(расш.)* | — | Завершить вход по cookies. |
| **Reset authentication** | — | Очистить все токены. |
